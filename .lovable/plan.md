

# برنامه بهبود سیستم احراز هویت

## خلاصه تغییرات
این برنامه شامل سه بخش اصلی است:
1. افزودن ورود با کد یکبار مصرف (OTP) به ایمیل
2. افزودن ورود با حساب گوگل
3. بهبود ظاهر دکمه‌های پیام‌رسان در صفحه اصلی

---

## بخش ۱: ورود با کد یکبار مصرف (OTP)

### چگونه کار می‌کند
کاربر ایمیل خود را وارد می‌کند و یک کد ۶ رقمی به ایمیل او ارسال می‌شود. با وارد کردن کد، وارد سایت می‌شود.

### تغییرات مورد نیاز

**۱. ایجاد Edge Function برای ارسال ایمیل فارسی**
- ایجاد فایل `supabase/functions/send-otp-email/index.ts`
- استفاده از Resend برای ارسال ایمیل با قالب شیک فارسی
- محتوای ایمیل شامل:
  - لوگوی گپ‌گرام
  - کد OTP با فونت بزرگ و واضح
  - متن فارسی زیبا

**۲. به‌روزرسانی صفحه Auth.tsx**
- افزودن تب برای انتخاب روش ورود (رمز عبور / کد یکبار مصرف / گوگل)
- افزودن فرم OTP با کامپوننت InputOTP
- مدیریت حالت‌های مختلف (وارد کردن ایمیل، وارد کردن کد)

**۳. به‌روزرسانی useAuth hook**
- افزودن متد `signInWithOtp` برای ارسال کد
- افزودن متد `verifyOtp` برای تأیید کد

---

## بخش ۲: ورود با حساب گوگل

### تغییرات مورد نیاز

**۱. فعال‌سازی Google OAuth**
- استفاده از ابزار `configure-social-auth` برای فعال‌سازی Google
- این ابزار به‌طور خودکار ماژول `src/integrations/lovable` را ایجاد می‌کند

**۲. افزودن دکمه گوگل به صفحه Auth.tsx**
- دکمه "ورود با گوگل" با آیکون گوگل
- استفاده از `lovable.auth.signInWithOAuth("google", ...)`

---

## بخش ۴: بهبود دکمه‌های پیام‌رسان

### مشکل فعلی
دکمه‌ها در صفحه اصلی تمام عرض باکس را پوشش نمی‌دهند.

### راه‌حل
به‌روزرسانی `src/pages/Index.tsx`:
- تغییر چیدمان دکمه‌های پیام‌رسان به گرید ۵ ستونه
- افزودن کلاس `w-full` به دکمه‌ها

---

---

## پیش‌نیازها

### ۱. کلید API از Resend
برای ارسال ایمیل‌های سفارشی فارسی، به کلید API از Resend نیاز است:
1. به https://resend.com بروید و ثبت‌نام کنید
2. دامنه خود را تأیید کنید: https://resend.com/domains
3. یک کلید API بسازید: https://resend.com/api-keys

### ۲. فعال‌سازی Google OAuth
این به‌طور خودکار توسط Lovable Cloud انجام می‌شود.
